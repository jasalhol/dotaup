5 minute vibecode for personal use

Kill tracker for 34 Dota 2 heroes. Each card shows the hero's portrait, their current kill count, and + / - buttons to adjust it. Click the number directly to type in a value. Cards automatically sort by who's closest to their next checkpoint (10, 20, 30, 40, 50) after a 2 second pause, and grey out once they hit 50. Has a search bar to filter by name and a reset button to wipe everything back to zero. All counts save in the browser so they survive a refresh.
